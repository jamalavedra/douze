# Security policy

## Reporting a vulnerability

Please report vulnerabilities through [GitHub's private vulnerability form](https://github.com/jamalavedra/douze/security/advisories/new).
Do not include credentials, private MCP URLs, captured dashboard data, or exploit details in a
public issue.

Include the affected commit or release, the impact, reproduction steps, and any suggested fix. Only
the latest release and `main` receive security fixes.
