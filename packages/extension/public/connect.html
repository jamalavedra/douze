Douze

Use Douze with ChatGPT or claude.ai

ChatGPT, claude.ai and Dust run on someone else's computer, so they can't reach this one by themselves. Connecting gives them a web address to call instead. What they ask for is answered here, by the Douze already running in this browser, and nothing new starts listening on this computer.

Leave this as it is unless you run your own relay. The one Douze offers is run by Jaume Alavedra, who wrote Douze, on a personal server — not a company, and with no agreement behind it. Whoever runs a relay can read everything that crosses it — see below.

You can stop sharing at any time.

Where to paste it

  • ChatGPT — Settings → Connectors → Developer Mode → add a connector
  • claude.ai — Settings → Connectors → Add custom connector
  • Dust — Admin → Tools → Add MCP server

What a hosted assistant may do

Deleting is never possible from a hosted assistant, whichever of these is on.

Results that look like passwords

When a tool's answer contains something shaped like a password, key or token, Douze holds the whole answer back and says so. If a tool's answers always look like that and you meant to send them, allow it here.

The two lists are kept apart on purpose: allowing a tool for an app on this computer does not start sending that value to whoever runs the relay.

Apps on this computer

    Hosted assistants

      Douze has no tools set up yet, so there is nothing to allow.

      An app on this computer

      An app on this computer gets everything, including tools that delete things, so Douze will not take one on trust just because it is running here: the app prints a short code, and typing it in is you saying yes.

      On this computer is not the same as staying on this computer. Claude Code, Cursor and Claude Desktop are AI assistants too, so whatever a tool returns goes on to their own model provider — including results from the tools that delete, which a hosted assistant is never allowed to run.

      Pairing lasts until you undo it here.

      What you are trusting

      • That link is the password. Anyone holding it can call these tools.
      • The relay operator can read and inject every message that crosses it — your tool arguments and full result bodies.
      • The AI platform stores whatever your tools return, under its retention policy rather than yours.
      • Those result bodies are live data from your dashboards, fetched from your account just now.
